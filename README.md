## ☀️ Summer Theme Alignment & Bot Jam Overview
**ScoopSim** is the ultimate summer-themed Discord economy & business simulation game where players build, manage, and expand a global ice cream franchise empire!

From beach boardwalk stands in Miami and Venice Beach to real-time dynamic weather heatwaves, mobile catering truck expeditions, and tropical fruit sorbet crafting, ScoopSim embodies the spirit of summer fun!

---

## 🌟 Key Features

### 🍦 1. Active Interactive Serving Minigame (`/stand`)
- **100 Unique 16:9 Retro Pixel Art Order Visuals**: Interactive customer orders with dynamic speech bubbles and customer archetypes.
- **3-Step Order Serving Engine**: Select scoop flavors, choose cone/box sizes, and add gourmet toppings (fudge, sprinkles, caramel, cherries).
- **🔥 FEVER FRENZY Mode**: Achieve 3 perfect serves in a row to trigger **Fever Frenzy** (+100% Cash sales surge & 2x EXP!).

### 🌎 2. Global Widescreen Market Exploration (`/map`)
- Expand your franchise across **15 real-world countries** (USA, Italy, Japan, Brazil, Egypt, France, Australia, Belgium, Iceland, South Africa, Mexico, India, Germany, Spain, Canada).
- Real-time country weather demand multipliers and local flavor preferences.

### ☀️ 3. Summer Bot Jam 2026 Special Event (`/summer`)
- **Boardwalk Festival**: Dedicated Top.gg Summer Bot Jam 2026 command with 16:9 pixel art boardwalk banner.
- **Summer Festival Pack**: Claim $10,000 Summer Cash & 3 Prestige Tokens.
- **Tropical Flavors**: Unlock Mango Sorbet and Watermelon Splash in `/shop`.

### 👑 4. Executive Server Telemetry & Admin Command Center (`/admin hub`)
- Double-locked executive admin dashboard for bot managers.
- Server telemetry inspector, economy wipes, server blacklists, user fund credits, and live event triggers.

### 🎉 5. Live Giveaway Network & 15-Command Reminder Engine
- Modal-driven giveaway announcement builder with Component V2 draft cards.
- Automated reminder engine popping up on a user's 1st command and every 15 commands.
- VIP Direct Message receipts and crypto-random winner drawing (`giveawayWinnerEngine.ts`).

### 💬 6. Automated Discord Server Setup Engine (`/admin setupdiscord`)
- Auto-creates server roles, categories, and channels.
- Attaches and pins Component V2 banner cards with 16:9 retro pixel art imagery across all channels.
- Integrated private support ticket desk (`/ticket`).

## 🛠️ Technology Stack & Architecture
- **Language**: TypeScript (Strict ES2022)
- **Framework**: Discord.js v14 (Components V2 API: `ContainerBuilder`, `TextDisplayBuilder`, `MediaGalleryBuilder`)
- **Database & ORM**: SQLite + Prisma ORM (ACID transactions via `safeTransaction`)
- **Graphics Engine**: Node-Canvas 16:9 Widescreen Renderers (1200x675 resolution)
